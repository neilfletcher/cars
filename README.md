# Logbook: 34 Cars

Every car I've owned, from an MG B GT to a Bentley Continental GT, with the stories I told on PistonHeads and beex at the time.

Single static page (`index.html`), no build step. Hosted on GitHub Pages at https://neilfletcher.github.io/cars/

To add a car, append an entry to the `CARS` array in `index.html` and update the stats in the masthead.
